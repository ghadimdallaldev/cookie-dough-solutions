# Cookie Dough Solutions — brand assets

Official logo mark (use from now on):

| File | Use |
|------|-----|
| `logo-mark.svg` | Nav, favicon, light backgrounds |
| `logo-mark-dark.svg` | Supplify / dark sections |
| `logo-lockup.svg` | Presentations, exports |

The mark is three chocolate chips on warm cookie dough — the parent company identity. **Supplify** keeps its own product styling on `/supplify`; always pair it with “A Cookie Dough Solutions product.”

Optional: generate a richer raster logo with Higgsfield and save as `public/images/logo-raster.png` if you want a photographic variant.

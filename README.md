# Cookie Dough Solutions — Marketing Site

Portfolio site for **Cookie Dough Solutions** (F&amp;B software studio) with a dedicated **Supplify** product page at `/supplify`.

This project lives **outside** the supplify_erp monorepo.

## Run locally

```bash
cd cookie-dough-solutions
npm install
npm run dev
```

Opens at http://localhost:5180 — **Home** `/` and **Supplify** `/supplify`.

## Build

```bash
npm run build
npm run preview
```
